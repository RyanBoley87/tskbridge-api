This file records the prompts used to generate the inherited Project Service and supporting repository setup.

## Prompt used to generate the inherited Project Service

## Prompt used to establish project conventions

"Set up a Node.js TypeScript project for a multi-service API with a `src/projects` service and a future `src/notifications` service, including a README and standards for security, testing, and architecture."
